# Upstream issue and pull request status — 0.5.1

**Release status:** [0.5.1 is published](https://github.com/KimYeongHyeon/obsidian-citation-plugin/releases/tag/0.5.1) after independent review, 83 tests, actual-app checks, and verification that the release assets match the tested build. Version 0.5.0 and its assets remain withdrawn.

Snapshot of the 160 upstream issues and 15 open pull requests captured on 2026-11-04. Each row distinguishes evidence from implementation and release status. Issue and PR numbers link to the original reports; source links point to the released `0.5.0` tag except where explicitly marked as `0.5.1`. Both source tags are available for inspection. The issue findings are based on [the full triage](UPSTREAM-ISSUES.md); PR adaptation details and release verification are in [the maintenance record](MAINTENANCE.md).

**Verdict:** `confirmed` means the relevant behavior was verified with the reported input or a documented regression; `partial` means only part of the request or a related path is covered; `unverified` means the original report has not been verified; `open` means an identified defect remains; `request` means a feature, documentation, or discussion request rather than a confirmed defect. `yes` in code means the relevant implementation exists, not necessarily that the original report is fully resolved. `0.5.0 withdrawn` identifies code that was published and then withdrawn; it is not available or approved for installation. `0.5.1` identifies the published replacement; the verdict still distinguishes verified resolution from partial or unverified coverage.
